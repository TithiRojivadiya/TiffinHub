# TiffinHub

TiffinHub is a MERN-based tiffin subscription platform designed to manage food subscription plans for users and vendors.  
The project focuses on backend architecture, authentication, subscription workflows, and RESTful API development.

---

## Features

- User and Vendor Authentication
- Role-Based Access Control
- Vendor Subscription Plan Management
- CRUD Operations for Tiffin Plans
- Subscribe to Multiple Plans
- Pause and Resume Subscription
- Manual and Automatic Resume Workflow
- Unsubscribe and Re-Subscribe Features
- RESTful API Architecture
- Secure Backend Implementation

---
